### 🚀 Projetos em Destaque

* **[AI Learning Tutor](https://github.com/lucamachado49/learning-tutor)**
  Um tutor de idiomas e temas técnicos que funciona por texto e voz, todo rodando local. Usa RAG sobre livros, LLM via Ollama, Whisper para transcrição e Piper para a voz. Também tem revisão espaçada e avaliação de pronúncia.

* **[Arche](https://github.com/lucamachado49/Arche)**
  Meu projeto para o Desafio Quant AI 2026 (Itaú Asset). Trato o mercado de ações como uma rede de correlações e uso a curvatura de Ollivier-Ricci para achar ativos "fora do lugar". O sinal passa por backtest walk-forward e decomposição Fama-French, e tem um teste dedicado só para pegar look-ahead bias.

* **[MaterFlow](https://github.com/lucamachado49/materflow)**
  Feito para reduzir faltas em consultas numa rede hospitalar, com 279 mil agendamentos reais. Em vez de prever quem vai faltar, uso uplift modeling para achar quem muda de comportamento ao receber um lembrete. Depois o Gemini escreve a mensagem para cada paciente.

* **[Vectra Health](https://github.com/lucamachado49/Vectra-Health-Engine)**
  Prevê o risco de surtos de dengue, zika, chikungunya e malária a partir de dados climáticos, espaciais e epidemiológicos. Usa XGBoost com explicabilidade e um agente LLM que ajuda a interpretar os resultados.
