Sou proativo, adaptável e focado em resultados tangíveis, com o objetivo de otimizar decisões estratégicas e gerar valor através de análises quantitativas precisas. Busco um estágio onde possa aplicar minhas habilidades para evoluir tecnicamente e contribuir com o sucesso de uma equipe de ciência ou engenharia de dados, análise quantitativa ou de risco.

### 🚀 Projetos em Destaque

* **[SentimentQuant: Sistema de Trading Algorítmico](https://github.com/lucamachado49/SentimentQuant)**
    Um sistema de trading quantitativo que prevê movimentos de preços de criptomoedas usando análise de sentimentos do Twitter e modelos de Machine Learning (HMM e LSTM). O projeto foi inspirado nas metodologias de Jim Simons.

* **[TradeSmart: Estratégia de Trading com RSI](https://github.com/lucamachado49/tradesmart)**
    Desenvolvi uma estratégia de reversão à média com RSI para ações da B3 usando Python. O backtesting alcançou 15% de retorno anualizado em 2024 e reduziu o drawdown em 10% com otimização. A visualização dos resultados foi feita com Streamlit.

* **[Pipeline ETL de Dados Financeiros](https://github.com/lucamachado49/finance-pipeline)**
    Construí um pipeline ETL automatizado com Airflow para ingestão de dados de ações via API, com armazenamento em banco de dados Oracle.

* **[IBM + FIAP Challenge](https://link-para-o-projeto)**
    Projeto com foco em aumentar a receita no varejo farmacêutico por meio de vendas cruzadas entre produtos de saúde e eletrônicos. O modelo gerou sugestões de combos personalizados, otimizando o ticket médio e a experiência do consumidor.
